# Racing Drone Simulator

Interactive 3D racing drone simulator developed in **C++** and **OpenGL**.

## Features

- 3D graphics and rendering
- Physical simulation
- Interactive drone movement
- Stadium environment
- OpenGL-based visualization

## Technologies

- C++
- OpenGL
- 3D Graphics
- Physical Simulation

## Setup

The stadium model uses an external binary file.

Before running the project:

1. Go to the stadium model folder.
2. Extract `stadium_v_4.rar`.
3. Make sure `stadium_v_4.bin` is placed in the same directory as `stadium_v_4.gltf`.

## Project context

Academic project developed as part of the Computer Engineering degree at Universitat Autònoma de Barcelona (UAB).
